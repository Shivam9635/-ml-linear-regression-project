🏡 California Housing Price Prediction using Linear Regression

📌 Project Overview
This project is a Machine Learning implementation of **Linear Regression** using the California Housing dataset.  
The goal is to predict house prices based on various housing features such as income, population, number of rooms, and location-based attributes.

🎯 Objective
To build a regression model that can predict median house prices and understand the relationship between different housing features and price.

📊 Dataset Information
- Dataset: California Housing Dataset (from Scikit-learn)
- Features:
  - MedInc (Median Income)
  - HouseAge
  - AveRooms
  - AveBedrms
  - Population
  - AveOccup
  - Latitude
  - Longitude
- Target:
  - Median House Value (Price)

🛠️ Technologies Used
- Python 🐍
- Jupyter Notebook 📓
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

🔄 Workflow
1. Data Loading and Preprocessing  
2. Exploratory Data Analysis (EDA)  
3. Data Visualization (Distribution & Correlation Analysis)  
4. Train-Test Split  
5. Model Training using Linear Regression  
6. Predictions on Test Data  
7. Model Evaluation using:
   - Mean Squared Error (MSE)
   - R² Score  
8. Visualization of Actual vs Predicted values  
9. Residual Analysis  
10. Final Conclusion
